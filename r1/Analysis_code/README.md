# Revision analysis files

This folder contains the released survey and eye analysis code and aggregate results. Raw participant records and identity crosswalks are excluded. The 24 image files are available separately in `../stimuli/images/`. Software is MIT-licensed; aggregate tables and stimulus materials are CC BY 4.0.

## Reproduce the survey and eye results

Use Python with pandas and openpyxl, and R with lmerTest, emmeans, dplyr, and tidyr. The tested R versions are in `sessionInfo.txt`. From this folder, with the two retained private source workbooks available:

```sh
python3 prepare_source_inputs.py --survey-xlsx "/path/to/survey.xlsx" --eye-xlsx "/path/to/eye.xlsx" --membership analysis_specification.json --output-root "/path/to/fresh_run"
Rscript reanalyse_survey_eye.R "/path/to/fresh_run"
```

Use a new writable output folder. Sources are opened read-only and checked against their SHA-256 digests. No name, telephone, account, or identity-crosswalk field is written. `inputs_private` contains pseudonymous participant observations and is not included in this bundle. Pseudonyms are generated by sorting the trimmed, lowercase private source key. This is a reproducibility key, not an assertion that individual data can be released without further review.

`analysis_specification.json` makes the existing questionnaire block-condition coding and the retained 37-person eye sample explicit. The script reproduces those decisions; it does not independently verify the administered sequence or historical acquisition-quality exclusion rule. All 40 complete questionnaires are retained; three records have no entries in the rating fields. Single-choice cue questions contain one category per person, as confirmed by the investigator. Questionnaire block indexes in the code do not resolve the separately deferred administered-trial count.

The long-input columns are ID, Group, Condition (Standard/Faceless), Metric, Value, and Trial or Media. The script retains all 48 eye export fields. The R script excludes four administrative fields from inference and identifies constant or insufficient-data outcomes. It averages within participant and condition, uses complete paired observations by outcome, reports Faceless-minus-Standard paired differences, 95% confidence intervals and dz, and fits exploratory group-by-condition mixed models. FDR families are five survey outcomes or 48 eye fields, separately for pooled condition tests and each exploratory-model effect.

`reproduction_verification.json` records equality of the rebuilt inputs (2400 survey rows, 21312 eye rows, and 40 cue records) and the three result tables (49 pooled, 90 descriptive, and 135 model rows). Two singular-fit messages from the exploratory models are retained in `rerun.log`; results are not presented as uniformly well-conditioned confirmatory models. `sessionInfo.txt` records the rerun environment.

## Stimuli and fNIRS

`stimulus_manifest.csv` is the original 12-asset/six-pair project inventory. `../stimuli/stimulus_manifest.csv` covers the current 24-file/12-pair release, including the author-confirmed CC BY 4.0 license. `STIMULUS_AVAILABILITY.md` explains this provenance distinction. The validation checklist is Supplementary Appendix B.

`fnirs_original_HbO_all_ROIs.csv` and `fnirs_original_descriptives.json` are transcribed archived Quest outputs, not outputs of this R script. The separately retained SNIRF reconstruction does not reproduce unknown original Quest settings. The original project, historical replacement counts, and matching ON/OFF outputs remain necessary to resolve the corresponding reviewer request.
