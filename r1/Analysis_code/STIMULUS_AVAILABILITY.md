# Stimulus availability and inventory

The retained Tobii project contains 12 named B-task image assets (six Standard and six Faceless files). `stimulus_manifest.csv` records their labels, condition, dimensions, SHA-256 digests, and project identifiers. These are asset counts, not an adjudication of the number of administered trials. The inventory establishes what is preserved in the project; it does not prove that archived bytes were unchanged since data collection.

No image-specific permission to redistribute was established by the reviewed project descriptors or embedded rights metadata. Local import paths and editing metadata do not establish photographic authorship or a reuse license. Therefore the review code bundle provides the manifest without the image binaries. The original files and private source trace are retained locally for the author to resolve image-specific source, attribution, and permission. This does not assert that the images are prohibited from sharing or that permission has been granted.

The stimulus-validation checklist is reproduced in Supplementary Appendix B. It should not be interpreted as an independent validation of equal valence/arousal across conditions. Public deposition and image redistribution have not been performed.
