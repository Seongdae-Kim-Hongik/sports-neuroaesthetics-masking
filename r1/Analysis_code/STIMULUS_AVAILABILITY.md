# Stimulus availability and inventory

The public release contains **24 image files, forming 12 Standard–Faceless pairs**, in `../stimuli/images/`. The current complete manifest and original-to-new filename mapping are in `../stimuli/stimulus_manifest.csv`.

The retained Tobii project contains 12 named B-task image assets (six Standard and six Faceless files). The local `stimulus_manifest.csv` retains that earlier project inventory. All 12 archived hashes match pairs 01–06 of the current release. Pairs 07–12 were newly supplied by the author on 7 November 2026. Counts match the manuscript's 12 base images / 24 versions; actual presentation order and project linkage of the added files have not been independently reconstructed.

The corresponding author confirmed authority to license all 24 image files openly and authorized public release on 7 November 2026. They are provided under CC BY 4.0, without an approval requirement for access. Source photographic URLs and original creator/provider credits were not supplied and have not been guessed. Historical rights fields in the project inventory predate this authorization.

The stimulus-validation checklist is reproduced in Supplementary Appendix B. It should not be interpreted as independent validation of equal valence/arousal across conditions. This archive does not change the analysis block mapping or establish original Quest-processing settings.
